# 艺术标题与主题生成笔记

记录日期：2026-10-14。依据为八张静态参考的抽象观察、二十组标题实验及现有渲染接口。这里只保存方法和案例编号，不分发用户参考图、原片、标识或水印。

## 从画面事实形成主题

先写可见事实，再写创作联想。手在编织、列车转弯、咖啡流进杯中属于事实；“一起向前”“把自己交给浪”属于联想，不能扩写成素材没有证明的经历。短题可作为场景名称，长短句可建立情绪；两字题名只是一个选项。选词之后标出脸、手、工具和动作范围，再决定标题的重心与留白方向。

## 静态参考提供的知识

参考显示了细线手写、亮色飞白、粗实干笔、墨色行书、竖排印刻等差异。值得保留的是粗细交替、干湿变化、长拖笔、大小字关系和不等宽结构。两行错落、窄竖题、大字配小注释，均能形成层级；短线、点饰和小英文只辅助主字。饰物应呼应题材，不机械添加同一个红章，不伪造署名、地名或不懂的外语。

八张图只有静态证据，不能证明动画轨迹、显现顺序、节奏、声音或原工程实现。生成器提示词应写准确文案、行序、主辅比例、笔触和收笔方向，而不只写“书法”。不复制参考原句、电影标识和背景插画。

## 字图、布局与配色

主字画高约20–35%、辅字约为主字40–65%可作小样起点，最终按分辨率与实际笔画辨读。实际字形由 alpha 包围框决定；PNG 的透明边框不代表字形尺寸。先确定笔画目标范围，再反算整张PNG的位置、宽度与旋转中心，保留生成原件。

先选标题区域，再从实际底片提取2–4色，区分直接采样与为对比调整的颜色。浅背景可用深墨，暗背景可用暖浅色，鲜青、粉紫等也可有场景依据。元数据中的声明色号只是设计意图，不等于所有抗锯齿、飞白和半透明像素都具有同一实测色。不能用整图平均亮度代替文字脚下的局部对比。

生成后逐字核对中文，检查真实alpha、四角透明和实际背景边缘。黑色查看器让深墨显暗，不表示字图有黑底；有RGBA也不保证透明。完整字体文件需字形覆盖与缺字回退检查，生成标题PNG则需人工核字。PNG不是新造的TTF字库。

## 分层与时间表达

主字、副字和需要单独移动的饰物各用独立透明层。主字先稳定、副字稍后轻入、饰物最后出现，可建立阅读顺序。少量顺势平移、缓慢淡入或曲线入场服务于字势；不能让所有元素同幅度运动。留足静止阅读时间，关键动作靠近标题时提前退出。

```json
{
  "type": "curved_path",
  "cubic_bezier_points_px": [[-90,35],[-45,-50],[30,-25],[0,0]],
  "enter_s": 0.8,
  "settle_s": 0.25,
  "overshoot_px": 5,
  "from_rotation_deg": -8,
  "rotation_deg": 0,
  "exit_s": 0.45,
  "easing": "smoothstep"
}
```

这是60fps项目可对齐帧的示例，点为相对静止位置的画布像素。代码计算真实三次贝塞尔路径，末点回到零；旋转正角为顺时针。代码与工程共用逐帧运动表，原生写逐帧线性关键帧，并非原生贝塞尔控制柄。整张PNG淡入不等于逐笔书写；真实运笔还需路径或逐笔蒙版。

## 二十例暴露的修正

| 案例 | 实际采样发现 | 采用的修正 |
|---|---|---|
| T03 | 小字融入暗云 | 移向亮天空并放大 |
| T04 | 米白字压浅布、墙 | 下移到绿叶区域，让开双手 |
| T06 | 织线饰物碰辅助字 | 饰物下移，局部放大复核间隔 |
| T09 | 尾笔靠近头发 | 上移；稳态边距合格不能外推全程 |
| T10 | 深蓝笔画被暗窗吞没 | 单项增加细暖浅边并重算alpha布局 |
| T14 | 辅助层被夹回末字内部 | 辅助移入独立空区 |
| T16 | 冲浪者向左进入标题区 | 缩小主字，按动作范围让位 |
| T18 | 浅金细笔融灰绿草丝 | 改深森林墨、删拥挤英文 |

这些问题证明，静止位置、单张好看的字图和提示词里的书体名不足以完成设计。探索实验需同尺寸总览检查字形家族、布局、颜色与运动关系；连贯成片仍应维持自身统一性，不为凑数量换风格。

## 验收与能力边界

本轮二十例源区间以0.5秒间隔取九帧审看，最终采用版本各审看三张真实MP4抽帧，共60张。80秒总览有4800帧，完整解码通过、无音轨。此证据不等于连续播放、每帧人工审查或剪映界面验收；界面验证仍为false。人工保护矩形与对比数值只是提醒，没有自动主体跟踪或“审美分”。

工程保留原片、字图、辅助层及关键帧，位置、大小、旋转、透明度和时间可编辑；PNG内部字形与字内布局需要重新生成或替换。逐例记录应绑定源、字图、视频哈希、审看时间及修订版本，避免旧版验收被误用于新版。
