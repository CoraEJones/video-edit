# 调色、图像空间与画质笔记

记录日期：2026-10-14。依据为已整合的二十套原创SDR配方、色彩处理代码和标题实验。配方表达创意方向，不是相机Log还原、真实胶片测量或专业肤色校准。二十段标题实验保留背景原有外观，没有据此宣称完成二十套调色的真实素材盲评。

## 先确定输入空间

调色前保存原件哈希、传递函数、色域、矩阵、位深及相机信息。元数据是输入线索，不能单靠标签证明像素正确；标签缺失也不表示可以任意按SDR解释。标题PNG的sRGB、显式转换后的BT.709 RGB和未知RGB分别记录。画面中声明的颜色与实测像素、设计色号与透明边缘混合色也须区分。

当前创意LUT目标为BT.709 SDR编码RGB，不能直接吃线性RGB或Log。检测到PQ/HLG时，已知必要色域与矩阵后先走HDR→SDR映射；高光会改变，不能称HDR保留。未知标签需核对相机或前序转换后声明 `input_space:"bt709_sdr"`，声明本身没有转换能力。已知Log或不支持的空间应拒绝，不能为过校验假填SDR。广色域照片和ICC图像如需严格一致，也应先做受管理输入转换。

## 校正、匹配、风格的顺序

同场选参考镜头，先检查中性白、肤色、暗部、高光，再校正曝光与有限RGB白平衡增益。并排与连续比较相邻镜头，减少亮度、冷暖跳变。最后选择少量适合故事的外观和强度；风格改变应有段落依据。曝光运算不能恢复已剪切高光，统一LUT也不能自动解决光源差异。

处理顺序为：必要HDR映射→线性曝光和RGB增益→gamma→对比→饱和→创意look混合。曝光以EV表示；白平衡是三通道增益，既非Kelvin校准，也非灰卡识别。强度0和look为none仍保留基础校正，`enabled:false`才关闭该片段全部校正与外观。

```json
{
  "color": {"look": "warm_print", "strength": 0.65},
  "shots": [
    {"id": "a", "index": 1,
     "color": {"exposure_ev": 0.3, "white_balance": [1.02,1,0.97]}},
    {"id": "b", "index": 2, "color": {"look": 19, "strength": 1}}
  ]
}
```

这是省略时间线必需字段的参数片段，数值不是剪映滑块刻度。顶层提供默认值，镜头、视觉层和分屏可覆盖；白平衡数组整体覆盖。按完整设置生成33³ CUBE，四面体插值应用，缓存核对代码、配方、设置和CUBE哈希。

## 保留的二十种外观

| 方向 | 现有配方 | 首要检查 |
|---|---|---|
| 自然与柔和 | 自然通透、日系空气感、金色暖阳、柔粉奶油 | 白云层次、灰雾、肤色黄粉偏 |
| 冷暖电影 | 青橙电影、北欧冷调、橄榄电影、深蓝情绪、紫青霓虹 | 中性色偏移、肤色污染、暗部压死 |
| 胶片与回忆 | 褪色旧时光、暖调胶片感、清冷反转片感、可可棕调、怀旧棕褐 | 抬黑压白、蓝绿损失、故事语义 |
| 风景颜色 | 地中海青蓝、翡翠森林 | 海水白浪、叶片层次与绿色噪点 |
| 强风格与黑白 | 漂白旁路感、交叉冲洗感、经典高反差黑白、柔雾黑白 | 细节、中性色、人物背景分离 |

暖色保护是色相掩码，也会影响木头与沙滩，不是人脸识别。黑白强度1完全去色，低强度混回原颜色。名称只描述方向，暖调胶片感没有自动加颗粒。准确参数与建议强度以[配方数据](../assets/color/recipes.json)为准。

## 标题颜色也要动态检查

先在实际标题区提取主辅色，再调整明度和饱和度，不强求复用某个像素。对比应在笔画alpha覆盖的局部背景上计算，粗主笔与细线分开检查。T03暗云吞小字、T04浅布吞米白、T10暗窗吞深蓝、T18草丝吞浅金，均通过移动、放大、局部细边或换深墨修正。配色不能脱离字体粗细、纹理及主体运动；一帧可读不能证明整个显现区间可读。

## 原片保真与合成画质

工程直接引用完整原片副本并核对哈希，保留源编码、帧率、位深和色彩元数据。时间线缩放、裁切、HDR映射和合成仍会改变可见像素；最终H.264高质量编码不等于数学无损。默认质量策略按所选视频规格与有效播放帧率检查，不能为速度或小文件擅自降规格；旧低清MP4须从原片重建。

标题实验按854×480、60fps输出，每段240帧，原片直接参与最终编码；80秒总览复制兼容视频流，没有第二次有损编码。SAR按实际显示比例适配并保留原件；非方形像素的代码测试和工程回读仍不能证明编辑器实际显示等价。

## 验证与当前限制

数值测试覆盖identity、校正继承、黑白、混合、空间拒绝、缓存损坏和源不变；真实FFmpeg检查LUT、透明度及预览/最终一致性。它们证明数学和工程路径，二百段真实素材上的肤色、绿色、低光与镜头匹配仍需抽样盲评及人工审片。

带有效调色的剪映可编辑计划目前明确返回 `COLOR_NATIVE_UNSUPPORTED`，不会偷偷烘焙或忽略参数。可输出MP4或导出CUBE后人工应用；人工导入结果需在剪映播放和导出核对，不属于已验证的自动参数一致性。报告应分别写清代码检查、实际像素、人工采样与界面检查。
