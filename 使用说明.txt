回忆剪辑 video-edit · 1.6.0

两条入口，按你熟悉的方式选择：

一、有 Agent / vibe coding 经验：直接对话
安装 Skill 后，把这段话发给当前的 Codex 或 DeepSeek Harness：

“请使用 video-edit 剪辑我的素材。先检查 Skill 和环境，从我的描述中提取路径与需求；缺少的请补问。汇总制作确认单给我确认后，再开始分析和剪辑。”

也可以补充真实素材路径、输出位置、约两分钟、横屏、电影感、中文字幕、不配音、音乐由助手选择。没提供路径时，助手必须问你，不能猜。
只需要 Codex 或 DeepSeek Harness 中的一个。

二、第一次使用：大字向导
1. 下载 ZIP 并完整解压，双击“安装到助手.cmd”。
2. 选择一个助手；再选择只要 MP4，或 MP4 加可编辑工程。
3. 扫描已有软件：只要 MP4 就不需要剪映；要可编辑工程才扫描剪映，找不到再引导安装。
4. 安装 Skill，检查环境；有缺项时点击“自动配置缺少组件”。
5. 重新打开助手，复制安装窗口给出的请求。也可以点“开始选素材”，填写需求，保存后回到助手继续。

制作前会确认：
素材和输出文件夹、作品名、故事背景与主题、时长、横竖屏和节奏、字幕语言、配音、音乐、必留内容、艺术标题、原声处理、开头和结尾。
你已经说清楚的不会反复问。不确定的创作选项可以选择“由助手推荐”；输出位置可由助手建议，但仍需你确认。
确认制作单后才开始；在向导取消不会开始。之后改变关键需求，需要确认更新后的方案。

默认推荐：
艺术标题按画面颜色与留白设计；无生图能力或效果不佳时，用字体大小变化、错位或醒目大字。
艺术字图片能改大小、位置和时间，改文字内容需要重新生成；想直接改字请选字体方案。
原声严格审核，含混或嘈杂就静音。关键讲话轻度降噪仍不清楚则舍弃；变速原声静音。
中文字幕优先，中英第二，简单清楚。片头精彩快闪加上下黑幕，照片多可横竖走马灯；结尾放慢、呼应前文。
子助手按需要自动分工，无分工工具时按顺序完成，不用你设置。

交付：
只要 MP4：成片、字幕、故事稿和剪辑记录，无需剪映。后续重剪请保留原素材和所用外部音乐的位置。
保留工程：另外提供多轨剪映工程及所用完整原片副本。搬电脑时复制整个工程目录，用包内“修复并打开工程.cmd”。先保存并退出剪映，再登记工程。
剪辑不预压缩原片，合成使用未压缩帧流或无损中间片，只在最后编码 MP4。MP4 为有损 SDR，不能称为原片无损复制；HDR 原片保留。
修改时创建新版本，不覆盖原片或已有工程。可以自然地说“多留家人”“结尾再慢一点”。

安装与限制：
公开普通版不带完整离线组件，首次配置通常需要联网。语音识别、配音按需求检查；不需要就不强制配置。
安装软件和账号登录按软件自身窗口操作；已有软件直接复用。更新使用新版安装器，保留原有机器配置。
Skill 文件存在不等于助手已经加载；需要在助手会话中实际读取。
这是需要助手看帧、编故事的 Skill，向导仅负责收集需求。没有视觉或试听能力时，会说明尚未完成的审看，不能假称验证通过。
光流补帧、运动追踪、复杂人物抠像、连续曲线变速尚未自动支持。
技术与测试记录见 references/validation-status.md；自有代码文档为 MIT，第三方资产遵守各自许可。
