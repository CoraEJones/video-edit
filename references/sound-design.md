# 声音先参与叙事，再跟随精剪

选曲、生成草稿、留白、循环和系列变体，按需读 [配乐技巧2.2](music-scoring-2.2.md)。先写声音任务表，再落实下述现有接口；表格不是可执行字段。

用户选“只保留原声”时，不检索或添加 BGM、环境库音和拟音，audio_layers 留空；原声仍须过严格审核。没有合格原声就保持安静、交付时说明，不擅自加音乐。已有配音开关独立遵守。

在故事骨架成立后、锁定每个镜头长度前，决定音乐的情绪和起落。音频子智能体可与标题设计并行；先给它故事段落、选片时码、对白和已有音乐目录，返回少量候选、试听结论、重拍/乐句、环境音建议。主智能体决定最终用法并写入计划。没有子智能体时按相同步骤串行完成，不让新手选择技术角色。

## 音乐选择与卡点

- 用户指定音乐优先，其次从用户本地音乐库挑选：先看风格/情绪/时长元数据，再听候选的开头、发展与转折。不要因为文件名排在第一就选它。通常一个短片一首主音乐即可，明确情绪变化才加第二段；不按地点机械换歌。
- 在任务目录保存 `music-analysis.json`：源文件路径和哈希、实际试听范围、候选起音、确认重拍、乐句边界、情绪段落与选择理由。只有波峰不能证明是鼓点；人声、镲片、突发噪声同样能制造峰值。无音频理解/试听能力时保留“候选、待听审”，不能声称已经准确卡点。
- 先根据故事安排高潮与休息，再映射音乐。高潮可提高镜头密度、用人物行动/反应增加投入感；不强制每个节拍切换。动作完成、关键对白、情绪表情优先于踩点；长镜头可跨多个节拍。慢下来也可以成为高潮。
- 单个音乐片段的源重拍 `b` 映射为 `timeline_start + b - source_in`，只保留该片段覆盖区间的点。循环、拼接、裁切或换曲后重新映射；当前音频层不支持速度字段，不能对它套用视频 speed。将实际采用的切点和相应来源写到节奏计划，再精剪画面。
- 接歌尽量在乐句交界，按实际音量渐入/渐出；短促现场声、适当静默也是过渡。循环前先试听尾首，必要时用两个音频层短交叉淡化；`loop=true` 本身不能保证接缝无感。
- 没有合适本地曲目时可用现有程序伴奏作为可替换草稿，并明确来源。不要为一段示例文案自行下载其中提到的商业歌曲，也不要冒称程序伴奏是检索到的音乐。

`scripts/sound_library.py analyze --file <已选BGM> --start 0 --duration 180 --output <任务目录/music-analysis.json>` 可提前生成候选起音。结果时间基准是**源文件秒**，不是时间线秒；其 `candidate_onsets` 不是确认的 beats/downbeats。助手补充试听结论、乐句和选择理由，不让用户编辑 JSON。

## 现场音、环境音和拟音

原片声音默认静音。按 [原声审核](original-audio.md) 听过确切区间，清楚的关键讲话或特别有故事价值的同期声才可保留；普通背景噪音、差音质和所有变速原声舍弃。关键话语尝试轻度清理后仍不清楚就不用，字幕承接须先核实原话。字幕关闭不等于没有对白，但转录文字也不等于已经试听；自动闪避以实际输出的讲话事件为准。外加环境音须精选，不盖住人物。

| 需求 | 优先处理 | 外加时检查 |
| --- | --- | --- |
| 海边空间 | 留原片浪声，避开风噪片段 | 浪势、距离和画面一致；无海景不凭空加“海边事实” |
| 夏日安静 | 留蝉/鸟与停顿 | 蝉鸣和蟋蟀不是同一种声音；避免高频遮人声 |
| 街道/闹市 | 留现场人群与车辆 | 语言、室内外、密度符合画面；异地声仅作补充设计 |
| 下雨 | 留真实雨声 | 伞下、窗上、地面声音不同，按拍摄位置选择 |
| 打字/开门/脚步 | 动作同期声优先 | 短拟音对准可见动作，不把无关声音塞满全片 |

外加声音属于“后期补充/拟音”，在 `source_note` 明确记录，不把它当成拍摄现场证据，不据此推断地点、天气、人物言语。带可辨语言的人群声尤其要看适用场景。不能仅凭文件标签宣称已试听或适配成功。

## 音效库和下载

内置小型库位于 `assets/sound-library`，`catalog.json` 记录中文检索标签、原发布页、作者、许可 URL、核验日期、下载地址、哈希、实际探测时长和下载状态。这是 BGM 库之外的环境音/拟音库，不能自动拿蝉鸣当音乐。用户已有环境音优先；按需要使用，不默认全部叠加。

```text
python scripts/sound_library.py search --query 海浪
python scripts/sound_library.py verify --all
python scripts/sound_library.py fetch --id sea-waves
python scripts/sound_library.py analyze --file <音乐文件> --start 15 --duration 60 --output <任务目录/音乐候选.json>
```

这些是助手内部命令。无须向新手展示路径、哈希或命令行。`search` 搜本地已核验目录，不代表联网搜遍素材站。`verify` 校验哈希并完整解码；这不等于听审。`fetch` 按目录恢复缺失条目，单文件默认最多 15 MiB，已存在且校验通过则复用；失败返回真实状态，不能记为下载成功。

需要扩充时，由助手在原作者/原发布站逐条检索并核对授权，而非仅信搜索摘要的 “royalty-free”。默认优先无需账户、免费且允许再分发的 CC0；保留原页和许可链接、作者、核验时间、实际下载形式。复核后再加入目录，不收集整站。其他许可若要求归因应随工程交付归因文字；不能确认再分发条件就不打包。当前下载辅助仅接收已核对 CC0 的同域 HTTPS 文件，跨域 CDN/其他许可由助手单独审查后处理。

首批条目：海浪、蝉鸣、法国户外集市、伞下雨声、电脑键盘。均来自 [BigSoundBank](https://bigsoundbank.com/licenses.html)，逐条原页在目录中；集市含法语背景、伞下雨声具有近处伞面质感，不应当作任何场景都适用的通用原声。压缩 MP3 用于轻量音效库；需要更高规格时再按对应原页获取 WAV，不宣称它们无损。

## 写入剪辑计划与混音验收

使用 [剪辑计划接口](plan-format.md) 中的 `audio_layers`：每层指定 `kind=music|ambience|sfx`、本地 `path`、`start/duration/source_in/gain`、淡入淡出，以及 `source_note` 和来源/许可元数据。配乐少量连贯，环境音低强度按场景进入，短音效只在动作需要时出现。原片对白只在审核后输出独立原声音轨；静音是默认且正常的取舍，不必为了凑现场感强留噪音。

- 音乐、环境增强和音效层遇有效对白/配音均压低，过后平滑恢复。仍需听审是否掩蔽语言，不能依赖音量常数包办。
- 需要连续环境且有已审核或有来源的合适声音时，可保留稳定声底；有意静默不强行填声。使用 J/L 衔接时核对声音源区间和画面关系。
- 检查最终混音而非单独音效：是否爆音/截断/突然变响、尾音完整、循环接缝明显、对白能听清。耳机和普通扬声器试听时，低音量仍应懂关键语句。
- 输出 `audio-plan.json`、实际来源/许可与缺失项。没有可听播放能力时明确“结构/解码已验证，听审待完成”，不把完整解码当作音乐审美验收。

混音 WAV、最终 MP4 的 AAC 音轨及工程预览编码后分别生成 `audio-qc.json` 实测：整段 LUFS、真峰值 dBTP、响度范围 LRA。测量读取 FFmpeg `loudnorm` 的输入统计并丢弃处理输出，不修改音频或自动归一化；未确认交付响度目标时只报告数值，不套用通用平台标准。静音记为 `silent`，无音轨、缺工具、滤镜不支持或失败明确记录，不能冒称达标。既有默认选曲路径会从源0秒循环/截取并做配乐预处理；其固定预处理参数并非整片目标，报告必须说明循环接缝、乐句、结尾和听审限制。程序伴奏明确标为工具生成的可替换草稿。
