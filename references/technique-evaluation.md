# 2.3技巧与叙事验证

分开验证“学到的关系是否正确”“代码是否执行正确”“剪出来是否更好”。解码成功不能证明审美、声音或教程复现质量。

## 可复现的自动检查

运行现有测试集，设置实际 VIDEO_EDIT_FFMPEG、VIDEO_EDIT_FFPROBE，并记录版本；依赖见 requirements-base.txt。新测试不仅检查JSON，还解码渲染结果的像素、alpha和时间。Windows CI也运行真实FFmpeg测试，不用模拟器替代。

| 维度 | 观测与通过条件 |
|---|---|
| 连续变速 | 积分/逆函数往返误差、单调性与节点连续性；真实FFmpeg帧身份与解析PTS一致；整段编译曲线与等效恒速结果一致 |
| 定格/多格 | 指定源帧保持，播放转定格无透明间隙，各格中心颜色/位置正确 |
| 蒙版/透明度 | 羽化边缘有中间alpha，反转alpha互补，文字/资源蒙版乘原alpha；首末可见帧符合关键帧 |
| 混合/颜色键 | 效果只在指定区间生效，黑底滤色不改变区间外画面，颜色键去除指定颜色；透明背景保留 |
| 调色 | 使用原20套接口，曝光/白平衡/外观顺序不变；新技巧路径可加载LUT并保留alpha |
| 字体 | 实际字形、描边、发光像素与透明边缘；缺字体资源/非法参数/超画布拒绝，不能静默替代；缺字方框仍需实际审看 |
| 证据与文件 | 原片哈希不变、源越界拒绝、旧输出不覆盖、未知字段和非有限数拒绝；报告不伪造已审看或已试听 |
| 兼容性 | 旧主计划和完整剪辑流程回归通过，缓存/磁盘交接/音轨/导出不退化 |

学习卡同时核对源SHA256、时码、实际查看帧、ASR不确定项和执行路线。知识中的“直接数学表达”不意味着已经新增对应检测器；新字段必须有编译实现、实际输出和范围说明。

## Agent前向任务

让另一个Agent只读已安装Skill和任务要求，使用新的任务目录完成下列任务，再由独立审看者复核；不要提供答案图层。保存它加载的卡片数量、工具调用、重试、耗时、峰值内存和交接记录。

1. 从片中某个核实动作定格，再生成四格逐格停住，保持总时长。
2. 同一素材的调色前后比较擦除，包含透明文字与柔边蒙版。
3. 按已听审的三个重音生成轻度抖动，保留对白完整性，变速原声静音。
4. 用外部黑底烟雾叠文字，再用白底黑墨显照片，解释二者滤色结果为什么不同。
5. 镂空文字、发光标题、弹幕与片尾关注动画，保留字号、出入点和留白可调整参数。
6. 加重叠转场后重新求照片开始点，检查拍点事件是转场起点、中点还是结束，而非机械加固定秒数。
7. 缺烟雾资源、未知相机Log或只有ASR无试听时，明确缺项，不生成冒称复现/核实的报告。

先核验执行产物是否符合任务约束，再盲评。仅知识卡/截图抽查的教学记录不能算完成这些前向任务。

## 审美与200段素材压力测试

固定同一批真实素材、需求、模型/工具预算和音乐许可，比较1.7.1与2.0；覆盖旅行、人像、运动、低光、混合相机/帧率、照片与讲话。不要求技巧越多越好。请至少3名不知道版本的评审按1–5分评价叙事清楚、镜头动机、节奏、转场自然、主体与文字可读、光色连续、音乐与对白关系，以及装饰是否过量。汇报各项分布与失败案例，不合成为一个掩盖缺陷的“总性能分”。音频必须实际试听。

200段任务使用 [原基准流程](benchmark.md) 的真实来源与许可记录。预先标注必须保留的瞬间、可用区间及检索问题，以must-keep召回、precision@k、区间命中率、重复镜头、未看却引用、过期缓存拒绝率衡量证据质量；同时记录处理时长、磁盘、上下文加载条数与Subagent交接丢失率。中断/恢复及修改一个源文件后重跑，确认只重算受影响阶段并拒绝旧指纹。

自动检查、独立Agent前向结果、人工盲评、200段完整成片评测分别报告。当前教程学习与代码回归不能当作已经通过200段的审美评测，也不能证明特定剪映预设或原生工程界面兼容。

## 2.3真实教程素材与原生对照

以每课实际资源做一条最小案例，保存输入哈希、声明色彩、源区间、参数、首中尾画面和完整解码结果。资源缺失记缺失；借用其他课的素材只算通用能力测试。每课一例不等于覆盖该课全部原则，知识卡抽象数也不等于完全复刻的特效数。

原生路线分别统计 `native_layers`、`hybrid_layers`、`derived_composition`，记录可改参数和已烘焙操作。测试独立轨道、源文件哈希、真实缓存资源、加密读写及缺资源拒绝。然后在实际剪映中打开、移动一个关键帧、保存、读取当前工程并导出同区间；没有完成这一步，UI兼容和像素等价均为未验证。

重点反例：白底墨迹需按意图反转亮度蒙版；非方形像素按显示比例；头像蒙版须检查眼睛/嘴与资源圆框位置；专有声音缺失要明确替代音色；ASR字幕有时间码不等于词语核实。混合空间、文字单位和蒙版方向未校准时不能承诺剪映逐像素一致。

故事sidecar测试保护区不被切穿、候选源秒映射正确、缺证据和未知字段拒绝。连续速度积分与实际PTS样本分别做真实帧身份检查；声称“叙事更好”仍需固定任务、盲评和失败案例。配乐按 [2.2任务表](music-scoring-2.2.md) 验收，数字响度、生成事件和模型转录不能替代听审。
