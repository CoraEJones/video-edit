# 精彩片头与有余韵的结尾

先按故事与现有素材选择；以下是可复用起点，不是每部片的固定时长。片头应和正文节奏有明显区别，片尾则落到故事的情感终点。用户已指定风格时优先遵守。

## 首选：动作钩子 → 快闪 → 黑幕揭题 → 正文

此节奏提炼自用户认可的海岛旅行片头。保留节奏关系，不复制原片的人物、地点、标题、配乐或有损中间处理。

| 示例时间 | 镜头与节奏 | 执行判断 |
|---|---|---|
| 0–2.4 秒 | 一次有结果的精彩动作，可试三段各 0.8 秒、正常—慢—快 | 素材真实完整、源帧率足够才变速，所有变速镜头原声静音；不合适就用正常速度动作 |
| 2.4–3.0 秒 | 动作结果/水花/笑声反应等短镜头 | 要承接动作，而不是任意凑一个高能画面 |
| 3.0–4.6 秒 | 四个约 0.4 秒的场景/人物/细节快闪 | 每刀画面可辨认，提前预告后文主题；不泄露唯一的情感高潮 |
| 4.6–5.32 秒 | 切至短暂全黑，再上下揭开；先停 0.20 秒，再用 0.52 秒打开 | `mask_reveal={start:4.6,duration:0.72,hold:0.2}`；这是短暂全黑揭幕，不是整段固定黑边 |
| 4.85–7.85 秒 | 背景慢下来，短片名分词错时出现 | 可试三行 4.85/5.10/5.38 秒入场、字号递增、左右错位。艺术字图层也可分块进入 |
| 8 秒后 | 给一个稳定且能交代处境的正文镜头 | 镜头变长，进入人物/故事，不继续无休止快速闪烁 |

90 秒左右的片子可从约 6–10 秒片头试起；30 秒短片应更短。只有风景/照片时不硬造跳水等动作；用真实的视觉呼应或一个强烈细节开头。不会因写 `action_opening` 就自动产生这个结构，必须落实 shots、titles/visual_layers 与 mask_reveal。

音乐可在快闪段进入，或用一个经过审核的短声音作为钩子。旧参考片保留了变速原声，**这一点不沿用**。新版原声须按 [严格原声审核](original-audio.md) 过关；噪声不为“真实感”而保留。

## 照片多：前景横/竖移动，后景快速走马灯

主轨 `shots` 放快速切换的照片/视频，时长按画面信息量与实际音乐安排；前景 `visual_layers` 放一张值得停留的照片、透明艺术标题或少量图块，以 x/y 位置关键帧水平或竖直进入、短停、离开。选择一个主方向，同段不交错乱飞。

- 多张照片先按人物、事件、构图相似性组织，不能任意按文件名字典序播放。
- 背景通常每张 0.3–0.7 秒试剪；主角照片/标题应留足阅读和辨认时间，不能跟背景一起快到看不清。
- 横向移动适合横排风景、车窗/路上感；竖向移动可用于竖拍相册或向上展开的记忆。看构图选方向，不把所有照片挤成窄条。
- 主层和背景都使用原图片/视频，移动和缩放在时间线描述；不能先压成低清走马灯 MP4 再导回工程。
- `visual_layers` 的数组顺序决定覆盖顺序，y 正值向上；关键帧 time 相对本层起点，末点为 `duration - 1/fps`。精确字段及范围见 [计划接口](plan-format.md)。原生和预览都要检查进入、停留、退出、跨镜头边界。
- 不把全屏照片直接盖住背景却宣称是多层走马灯。前景照片需有适当 scale/留白，透明标题需确认 alpha 真透明；主体被裁掉时先改版式。

## 结尾：回应故事，不再堆新信息

先明确“经历之后留下了什么”。收束可采用前文人物/细节的短回望，再落到一个意味明确的长镜头：背影、握手、回望、海面、灯光熄灭或一次完整告别。回望必须出现过且有叙事关系，不凭空剪出成长/离别等未证实经历。

末段通常降低切镜频率与音乐密度，保留一个约 4–8 秒的呼吸；若源帧率/动作适合，可用慢动作，但不强制低帧率素材慢放，也不自动光流补帧。变速原声静音，用音乐尾音、审核合格的正常速度声音或适当静默承接。

结尾文字少而准确，可呼应片名或前面的一句真实话；不要用冗长大道理解释一切，不默认加入“感谢观看”。最后一句留够读完，必要时先撤字幕再停留画面，音乐和画面自然收尾。淡黑不是必需，可从约 0.6–1 秒试起，不能截断动作、话语和尾音。片头强、正文展开、片尾慢，是可用的情绪曲线，不是公式配额。

复核：片头有没有钩子而不是行程说明？快闪能辨认吗？正文入口是否稳定？结尾是否回应了前文具体的人或事？末尾是否留出了感受，而不是突然断掉？
