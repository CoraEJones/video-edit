# 实现来源与兼容性

剪辑计划延续本工作区已有电影旅行片项目的 shots / panels / titles / captions / chapters 结构。新的 CLI、向导、验证、打包和字体选择层与旧项目分离；不导入带固定机器路径和工程全局变量的历史脚本。

剪映草稿依赖 [aoguai/pyJianYingDraft](https://github.com/aoguai/pyJianYingDraft)，固定提交 80d521b28049bd81288b5e6ee85de310c3ac8d86，版本 0.3.0。原生工程加密调用接收电脑已安装剪映的 DLL，不分发剪映软件或 DLL。

运行依赖通过 requirements.txt 安装；公开普通版随附固定草稿库 wheel、两款有完整 OFL 许可的字体和五个 CC0 环境/拟音样本，详见 [第三方声明](../THIRD_PARTY_NOTICES.md)。不打包用户原片、Windows 字体、本机配置、完整开发环境或语音模型。运行组件离线包属于另一种分发方式，不属于本次公开仓库内容。各依赖和资产保留自身许可证；默认程序伴奏没有第三方录音。

本机验证版本：Windows、Python 3.12、剪映专业版 11.5.0.14471。剪映草稿格式并非稳定公开接口，版本升级后须重新做实际打开、播放、修改、保存验证。

真实测试确定的适配：WAV 音频时长需按毫秒补齐；蒙版池从库输出的 masks 转为 common_mask，并绑定本机实际矩形资源。剪映 11.5 保存的当前资源来自 effect/82432980；旧缓存 effect/636077 仅作后备，迁移时优先保留已经生效的资源路径。资源缓存位置来自本机配置和发现，不随安装包分发。

保存后需要同时维护根草稿与 Timelines 下的当前时间线。2026-10-12 用户确认真实素材样片及搬迁副本可以播放、显示三分屏，并报告修改后重新打开正常；回读文件中的指定标题仍为原文字，因此“指定标题修改落盘”未独立核实。详细状态见 [本次验证记录](validation-status.md)。这个结果不代表第二台电脑或所有剪映版本已经测试。
