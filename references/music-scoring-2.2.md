# 配乐技巧 2.2：从故事任务到可执行声音轨

适用于旅行、家庭、活动短片的选曲、配乐设计和返修。先遵守用户音乐偏好与[原声审核](original-audio.md)，再用本指南；只保留原声时跳过 BGM。本文是知识与工作流更新，不新增音乐生成服务或音频执行字段。

## 学习来源与适用范围

2026-10-13 阅读两篇用户指定文章，以下为精简学习结论，后续接口、示例和验收方法是针对本仓库的实现设计：

- [镜头表与音乐时间轴](https://aimusic-tools.com/academy/travel-vlog-shot-list-bgm-timeline-workflow)：先标出声音任务，再安排疏密、留白和主题回归；生成音频仍需重新对齐。
- [旅行配乐指南](https://suno.ing/zh-cn/blog/suno-travel-vlog-music-guide/)：先比较核心段，再考虑延长和同风格变体；检查无人声、衔接和整段听感。该站自称独立指南站，产品描述不是官方能力证明。

不复制文章的完整案例或提示词，不把其特定时长、BPM、音量差写成标准。生成工具和账户可用性按执行时核实；本技能不要求注册某个平台。Suno 官方将 [Remix](https://help.suno.com/en/articles/6050497) 用作多种编辑操作的集合，不能把这个名字当作“自动生成指定情绪版本”的保证。

## 1. 用声音任务选择音乐

粗剪已有故事顺序后，由助手在任务目录写 `music-cue-sheet.md`，不要求用户填表。每行是一次声音主次变化，可以跨多个镜头：

| 必需信息 | 如何作决定 |
| --- | --- |
| 时间线起止秒、关联镜头编号 | 随粗剪修订，不把源文件时码当成片时码 |
| 这一段要让观众注意什么 | 人物语言、可见动作、空间或情绪；只选有素材依据的任务 |
| 实际输出的讲话/原声区间及审核状态 | 未听审不能当成可用原声；有字幕不等于有声音 |
| 音乐角色 | 前景、背景、退出；“无音乐”与“所有声音静音”分开写 |
| 配器密度、脉冲、增益目标 | 分别描述，不能把降低音量冒充减少配器 |
| 选定音乐源区间、过渡及验收点 | 尚无曲目时标待选；拿到音频后填实际时码 |

检索候选时先用“任务＋听感限制”，再用流派词。比如家庭重聚段要托住拥抱后的停顿，就先找不会在停顿处突然进入主唱或鼓填充的区间。用户指定歌曲则先寻找它内部适合的片段，不擅自换曲。

## 2. 把情绪拆成可调整变量

以下是本技能的原创决策表，是试选方向，不是地点与曲风的固定对应关系：

| 画面任务 | 首先检查 | 不适配时优先改什么 |
| --- | --- | --- |
| 连续移动，需保持前进感 | 脉冲是否稳定，鼓是否分散注意力 | 换较少填充的区间，不先加快所有镜头 |
| 景别展开，需给空间感 | 延音能否跨镜头，声音是否过满 | 减少竞争旋律；开阔不等于提高音量 |
| 人物说话，需理解信息 | 与实际对白一起试听 | 先换稀疏片段，再调增益；必要时退出 |
| 情绪停顿，需保留反应 | 乐句是否提前替人物“下结论” | 延后音乐进入，保留动作和表情长度 |
| 结尾回望，需完成收束 | 是否有可用结尾及足够尾音 | 先找收束段，再决定片尾镜头长度 |

BPM 只描述拍速，不能代表情绪或每刀间隔。稳定拍速时每拍秒数为 `60 / BPM`；拍号与重拍须听审确认。优先对齐段落和动作，再选少数切点；不要为了规整拍点截断话语。

## 3. 候选比较与可选生成

通常比较少量候选的同一用途片段。保持近似播放响度，并叠实际对白试听，避免仅因更响就判定更合适。记录适配的源区间、失配位置和淘汰原因；没有试听能力时只提供待听候选。

需要生成且当前任务允许时，以此原创模板表达需求：

```text
用途：陪伴一段人物互动，重点是保留说话和停顿。
声音身份：选定一个主要音色作为贯穿线索。
发展：开头简洁，动作段有轻微脉冲，对白处减少竞争旋律，结尾自然收束。
限制：纯音乐；避免可辨歌词及在关键话语处出现突然重击。
编辑需求：提供可裁切的稳定段与完整尾音。秒数是剪辑目标，返回后需重新核对。
```

如果工具提供纯音乐开关，一并启用；提示词和开关都不能替代对意外人声的听审。生成失败先改导致失配的一个变量，保留其它条件，便于比较。长片扩展先验证核心片段；每次延长都重听新增段和接缝。系列变体保存共有音色、节奏倾向及原始提示词，逐次改变配器或能量，记录版本差异。无需为了一个短片制作整套变体。

## 4. 对齐、留白、循环的执行方法

- 在 `music-analysis.json` 延续已有的实际试听范围、重拍和乐句记录。源秒 `b` 的时间线位置为 `start + b - source_in`，只保留当前片段覆盖的点；裁切、拼接后重算。不要把自动候选起音标成确认重拍。
- 真正的 BGM 留白要求该区间没有音乐层覆盖。低音铺底仍属于音乐；若要保留，改记为背景。淡出应在留白开始前完成，淡入应在结束后开始，并逐层检查重叠。
- 乐句完整性优先于机械等长切块；检查接缝附近鼓型、和声与尾音。交叉淡化可能形成双重鼓点或叠加变响，不能把重叠等同于平滑。
- 决定音乐要继续推进、暂停后接续，还是跳到新的源位置。三者需不同的 `source_in`，不能用循环开关代替这个决定。
- 先调整音乐区间和画面切点；需要保音高变速、EQ 或分轨处理时，仅在当前工具实际支持且产物已验证时使用。主计划音频层没有这些字段；处理后另存派生音频、记录源哈希和处理方法，重新听审并使用其新时码。

## 5. 接回现有接口

`music-cue-sheet.md` 是助手设计记录，不是程序输入；不能将角色、密度或生成提示词直接写进 `audio_layers`。可执行字段以[计划接口](plan-format.md)为准。

| 设计意图 | 当前可实现方式 |
| --- | --- |
| 选用某段音乐 | `path/start/duration/source_in`，核对实际源时长 |
| 音乐退出再进入 | 两个 music 层，中间留间隙，分别设淡出/淡入 |
| 常量音量改变 | `gain` 为线性倍率；相对变化 ΔdB 的倍率为 `10 ** (ΔdB / 20)` |
| 对白避让 | 现有引擎按实际输出的讲话/配音事件处理；查最终结果，勿再盲目叠加相同衰减 |
| 自定义音量包络或配器抽减 | 现接口不接受任意 keys/duck/stems；另行处理并验证派生文件，或换可用片段 |

计算例：原 gain 为 0.25，再相对降低 6 dB，结果约 0.125；不是填 `gain=-6`，也不代表成片 LUFS 已达标。衰减量靠实际混音决定。

存在显式 music 层时会替代默认配乐；没有 music 层且允许配乐时仍可能走默认选曲路径。设计整片无 BGM 时要通过需求设置关闭配乐，不能仅删除全部层。

原创结构例（非可直接执行计划）：一条 36 秒时间线，BGM 在 0–10 秒使用源 4–14 秒，在 16–36 秒使用源 20–40 秒，10–16 秒仅保留已审核的讲话。首层末尾淡出包含在其 10 秒内，后层从 16 秒起淡入。若源重拍在 25 秒，则第二层对应时间线为 `16 + 25 - 20 = 21` 秒。源文件需至少 40 秒；任一叠加音乐覆盖 10–16 秒都会破坏预定留白。

## 6. 验收与修订

分开记录“设计完成、结构校验、实测、听审”，不相互替代：

- 对照声音表逐段检查角色、留白、实际对白和音乐源区间。缺少可用原声时重新判断该段，而非用噪声填空。
- 试听所有音乐进出、拼接、循环和话语首尾；查意外人声、音色毛刺、抽吸感、双鼓和被截尾音。
- 按现有 `audio-qc.json` 检查 WAV、AAC/预览的实测响度与真峰值。目标取自实际交付要求，不能凭“背景音乐”标签套固定值。
- 用耳机和普通扬声器检查关键语言与音乐存在感。听审记录包含文件版本和区间；音频换版后旧结论失效。
- 返修定位到问题：遮话先处理对应区间；循环突兀先改接缝；结尾拖沓先换收束段。不因局部问题默认重做整条配乐。

## 生成素材的来源记录

执行发布任务时重新核对 [Suno 官方授权说明](https://help.suno.com/en/articles/9601665) 和[混编授权说明](https://help.suno.com/en/articles/9604993)。2026-10-13 检索时不同日期帮助页对订阅、下载与旧曲的表述有差异，不固化“付费即可”或“一律不能追溯”的规则；按具体曲目的当前条款和账户证据核实。本文不据第三方教程保证商用权。
