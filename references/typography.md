# 字体与颜色的剪辑判断

艺术标题优先根据实际背景设计；具备生图/艺术渲染工具时按下文生成透明标题图，回退路径为 [字体库](font-catalog.md) 与本机字体的原生可编辑文字。`assets/fonts` 无需安装进 Windows 字体目录，公开版附两款有完整 OFL 的字体，本机还可配置自己的库；不能假设每台电脑都有全部历史精选字体。`doctor` 返回 available_families、curated_fonts（编号、显示名、内部名）与可选风格；以实际可用项选择。

每条实际文案都通过 fontTools 的 Unicode 字形表及非空栅格检查，避免免费版字库占位为空白；缺字自动选择后续候选，并在 typography-report.json 的 fallbacks 记录缺字与替代字体。没有任何字体能覆盖时返回 FONT_GLYPHS_MISSING，不能默默输出方框或删字。仅支持繁体/日文常用字的字体不算完整中文字体；Foundry 等可能不含数字。自动检查不能代替视觉审看。预览使用字体的传统 family 名称（preview_family），原生工程保存实际字体文件路径；这样 Happy Times Italic 不会被 libass 静默换成 Arial。

选中的用户字体及随附说明复制到新工程 `assets/fonts`，原生文字轨引用实际字体文件，预览的 libass 同时加载该目录。搬迁时重新绑定包内字体；Windows 系统字体仍用接收电脑已有字体并记录回退，不分发 Windows 字体文件。原始字体文件不修改，随附作者及许可说明保留；目录记录的许可元数据不等于已独立核实商业授权。

自动初选按故事气质：家庭偏江西拙楷配 Kaushan Script，轻快活动偏 Nishiki-teki 配 Womby，安静旅行偏汇文明朝体配 Happy Times Italic。洒脱书法使用云峰飞云体配 Kaushan Script。候选缺字时回退至本机清晰字体。讲话字幕优先普通字重的清晰黑体；细宋体、书法体用于短片名，避免用于长段讲话。Windows 变量字体有时默认落到 Thin 字重，未经画面确认不用于小字幕。

向导默认“自动搭配”。只有勾选“我想自己挑文字风格”才显示清爽现代、温暖手写、安静电影感、洒脱书法。风格不是字体数量限制。单条 titles/captions 上的 `font_family` 可指定实际 family，`font_id` 可指定 doctor 返回的文件编号，`font_family_en` 可独立指定英文搭配。请求字体缺字时同样记录回退。`color="#RRGGBB"` 可显式选择颜色。相同内部名称和字重的不同字体版本不能混用，否则预览无法可靠区分，返回 FONT_AMBIGUOUS；从多个文件版本中选一个即可。

## 根据用户提供的标题参考图设计

参考的是布局和用色逻辑，不照搬示例作品的字形或水印。标题允许有表现力，讲话字幕保持简洁。不要将标题规则套成“永远白字”或“永远禁用鲜艳色”。

1. 查看标题出现区间的开始、中间、结尾，以及镜头/主体移动后的画面。在画面中找连续、纹理较少、相对稳定的颜色区域，如天空、暗墙、水面、窗帘、虚化背景。先决定位置，再选颜色与字体。一个词尽量位于同一颜色分区；不要横跨天空、山脊、脸和高亮反光，导致半边可读半边消失。
2. 从画面实际调色板提取 2–4 个主/辅色。浅区优先深字、深区优先浅字；色相不同但亮度接近仍可能看不清，要看文字脚下的局部区域，不能只比整张图平均亮度。优先采用画面已有的颜色；需要时调整明度/饱和度，不强求完全同一个像素值。检查字的细笔画而不只是大色块。
3. 灯塔参考是典型：蓝色天空/海面的大留白承接暖黄标题，暖黄呼应灯塔光源，白色只作少量辅助。类似地，暗绿色草地可承接暖黄/米白，灰白窗帘可用较深紫色，暮色蓝紫留白可用浅色。具体必须看本片帧图；亮黄色落在太阳/白云、深蓝字落在暗夜都要换位置或调明暗。
4. 短片名用用户书法/手写字体，安静怀旧可用宋体，现代轻快可用干净黑体；中文为主、英文小字为辅，最多两种主要字体。用字号、疏密、错落和短划线建立层次，不靠密集装饰。字体有笔触质感不等于每条字幕也要艺术字。
5. 标题出现时间留足读完，动作密集/讲话密集处少加字。标题不遮脸、手部关键动作或主要地标；保持安全边距。小范围背景不稳定时，优先换位置/缩短出现区间，其次轻薄底色、细描边或小阴影（仅在后端真实支持时使用），不能以粗黑边补救所有问题。颜色在一次出现期间保持稳定，不逐帧闪变。

主助手或标题子任务在 `title-design.json` 记录：对应 titles 索引、审看帧/时码、背景色区/位置、色值来源、文字与局部明暗关系、字体文件编号/缺字回退、遮挡和首中尾检查。它是设计证据，导出要落实到 `titles` 的 `x/y/size/color/font_id`。当前 native 的 y 正值向上，避免将图片左上角坐标直接传进去。

## 生图标题与蒙版

有可用生图模型时优先为片名生成独立艺术标题，只给短标题、来自画面的配色、笔触与透明背景要求。使用对应工具，核对每个汉字、透明边缘和实际背景可读性；一次有针对性的修正仍不满意就回到字体库，不阻塞全片。没有生图时用原生文字轨做明显字号对比、分词错位、错时入场或一个醒目大标题，避免把所有词排成相同大小的居中小字。造型服从场景，不照搬参考图作品的字形、水印和标题内容。

`titles` 仍是原生可编辑文字，不放 PNG 路径。生成的透明艺术字加入 inventory，kind=image，用 `visual_layers` 的素材 id、起止、scale、x/y 和位置关键帧叠在视频上；位置、大小、时长可编辑，字形本身是图片，修改文案需要重生图或改为原生文字。可按词生成多个独立图层以错落入场，但同片气质一致。检查 alpha 真透明、分辨率足够、边缘无白框，不能把带底色的整幅海报当透明标题。

`mask_reveal` 是整幅开场矩形揭幕，不是人物自动遮挡文字。人物跟踪抠像、逐字复杂蒙版仍未自动实现，不写成已完成。横竖照片走马灯与艺术图层接口见 [计划格式](plan-format.md)，节奏见 [片头片尾](opening-ending.md)。

## 讲话字幕

默认简体中文；第二选择中英双语，中文为主、英文为辅并分轨，用户明确其他语言则遵守。普通黑体、稳定位置、少量细描边，单语通常最多两行；双语需分别控制行数与间距，不把四行长句挤在底部。按完整语义断句，避免单字跳闪、逐字弹跳和多色轮播。故事字幕用少量有依据的句子承接起承转合，每句对准相应动作/事件，保留无字留白；不用“后来我懂得了”等空泛句强造素材没有呈现的变化。人名/地名及原话不清楚就复核。读不完时调断句/时间，不无限缩字号。每条首中尾和镜头改变处查可读性与遮挡。

本版默认原生字幕字号 3.75（初测 7.5 的一半），双语中心固定为 y=-0.79 / -0.92；当前计划导出器不读取字幕对象的自定义 y，位置需在剪映内分别调整。英文靠近底部，导出到有播放器遮罩的平台时应在剪映内上移。低清预览设最低可读字号，不能用预览逐像素推断剪映字号；最终以剪映显示为准。将字幕安全边距、字号、间距和中英文顺序一起核验。

用户说字体不好看时，先在实际画面上准备 2–3 个小样，再让用户选择；别列几十个字体名称让新手猜。无需另装一个字体 Skill；这些选择由 video-edit 自身的字体判断流程完成。
