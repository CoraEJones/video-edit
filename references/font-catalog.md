# 字体目录与本机扩展

公开版只在 `assets/fonts` 内附带以下两款有完整 SIL OFL 1.1 许可说明的字体。实际可用文件、哈希、内部名称和字形覆盖信息以 `assets/fonts/catalog.json` 与 doctor 的 `typography.curated_fonts` 为准；原始许可见 [第三方说明](../THIRD_PARTY_NOTICES.md)。

| 公开版字体 | 适合的画面与文字 | 使用注意 |
|---|---|---|
| 志莽行 | 随性旅行、手记、轻松短题 | 手写感强，长句不优先 |
| 辰宇落雁 | 轻柔手写、手账、小段题记 | 细字且简体覆盖不全，按实际文字检查 |

下面是本机扩展库的风格参考，**不代表公开版包含或授予这些字体的使用、再分发许可**。开发电脑曾有 23 个字体文件、20 个内部字体名称；除上表两款外不随公开版分发。用户已有且可使用的字体可以通过配置 `font_dirs` 接入，未安装时自动选择实际存在且覆盖文字的字体或系统回退。Windows 系统字体也不随包分发。文件版本不是额外的视觉风格；Foundry、Womby、Nishiki-teki 同名版本每部片只用一种。

| 字体 | 适合的画面与文字 | 使用注意 |
|---|---|---|
| 汇文明朝体 | 旧照片、安静旅行、回忆片名，带旧书印刷质感 | 只用短标题，复杂背景上注意笔画纹理 |
| 令东齐伋春塘 / QIJIC | 历史建筑、古典景物、文艺短题 | 不含常规英文，独立配英文字体 |
| 江西拙楷 | 家庭、亲友、自然旅行，温暖有力的短句 | 中英分开搭配，讲话字幕仍优先黑体 |
| 云峰飞云体、三极行楷粗体 | 山海、动作开场、有力度的片名 | 云峰相对舒展，行楷粗体适合更有分量的短题 |
| 平方赖江湖飞扬体、三极泼墨体 | 动作、户外、节庆的强烈主标题 | 笔触复杂，不用作密集字幕 |
| Nishiki-teki（含马克笔版本） | 轻快活动、漫画感短题 | 样例中的“忆”缺字，不能当完整简体黑体 |
| Pop Futomaru / Open 版 | 活泼家庭、童趣章节标题 | 日文字库，部分简体字缺失 |
| 居酒屋体、洋葱楷书浓烈版 | 手绘、节庆、小段装饰题记 | 日文字库，必须检查实际文字覆盖 |
| Happy Times at the IKOB Italic | 安静旅行的英文副标题 | 斜体衬线，与汇文明朝体搭配 |
| Kaushan Script | 温暖家庭、自由旅行的英文短题 | 有明显手写笔触，避免长段讲话 |
| Womby | 活动、现代片头、简短英文地点名 | 字形呈大写视觉效果，不适合密集正文 |
| Cramaten | 复古海报、窄长英文标题 | 字形偏窄且装饰感强，标题保持短 |
| Foundry Font Pack | 婚礼、亲友、优雅英文手写标题 | 样例检测不含数字，年份要换字体 |
| Timotheos | 轻松、有趣的英文手写片名 | 大小写有强烈装饰形态，用前审看 |

默认自动初选只是起点。助手根据镜头背景、故事气质和字数决定是否换字体；同一片保持一套主标题/英文副标题搭配，别把所有字体混用。颜色仍按实际画面亮度、纹理和遮挡判断。具体接口、缺字回退与工程打包见 [字体与颜色](typography.md)。
