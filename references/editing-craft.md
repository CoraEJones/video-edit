# 旅行、家庭和活动片的剪辑判断

本页是可维护的剪辑方法库。方法是否适合素材与后端能否执行是两件事。别为了展示技巧牺牲人物、讲话和情绪。核查日期：2026-10-12。

开始选片先读 [素材审看合同](material-analysis.md)，其中规定多帧证据、区间质量、事实与解释的分离；组织故事和精剪时读 [故事与节奏](story-rhythm.md)，其中说明跨地点主线、音乐提前介入和实际计划字段。本页只查具体技巧。

| 方法 | 如何判断和使用 | 第一版执行方式 |
|---|---|---|
| 蒙太奇 | 把彼此呼应的动作、地点、表情组合起来，压缩时间或建立对比。先确定观众要感受到什么，再选镜头；避免误导成同一时间或地点。 | 模型审看片段，编排独立镜头 |
| 动作开场 | 用真实发生的跳跃、招手、推门、切蛋糕等动作抓住注意。留足起势和落点，别只用晃动假装有冲击力。 | 精确入出点，可分段恒速 |
| 慢—快—慢 | 指整片的镜头密度和声音节奏：先建立情绪，中段增加信息，结尾留呼吸；不等于把所有视频反复变速。 | 不同镜头长度＋声音层次，必要时分段变速 |
| 远中近组接 | 远景交代环境，中景交代关系，近景承载表情/细节。素材不具备时不强求；保持运动方向和空间关系。 | 模型标记实际景别并安排顺序 |
| 蒙版三分屏 | 用三条独立镜头并置同时发生的动作或相似构图。检查主体被中心裁切后仍可见；复杂背景和字幕密集时少用。 | 三条原生视频轨＋矩形蒙版；主轨保留黑底 |
| 蒙版揭幕 | 短暂的上下黑色矩形移开可配合动作或片名揭示，不要长时间遮住关键表情。 | 原生蒙版与位置关键帧 |
| J-cut | 下一场景的声音先出现，再换到下一画面。先确认声音确实属于下一镜头；0.1–0.4 秒可作为试剪起点。 | audio_lead、独立音轨 |
| L-cut | 上一场景声音延续到下一画面，可保留笑声、掌声、完整句尾。 | audio_tail、独立音轨 |
| 音乐卡点 | 对齐重要动作或场景转换；不是每个镜头都必须踩拍。长句不为拍点截断。重音候选先听审，讲话段让位给语义。 | 程序配乐的已知节拍；自选音乐的频谱起音候选；模型修订切点 |
| 错落标题 | 用短词分批出现，靠位置、字号、时间错开建立层次。每个词留够读完的时间；别遮住脸。 | 独立文字段和轻微位置关键帧 |
| 分段变速 | 同一动作拆成几个可编辑片段分别设置恒速；检查边界、原声和高帧率余量。 | 0.25–4 倍恒速，明确不是连续曲线 |

## 音乐与讲话

原声默认静音，按 [严格原声审核](original-audio.md) 仅保留实际听审清楚且有叙事价值的讲话/同期声。杂音、爆音、强风噪和变速原声舍弃；关键讲话轻度清理后仍不清楚就静音，用核实字幕承接。BGM 只在实际输出的关键讲话与配音处压低，句尾回升；字幕本身不代表此处有声音。无用户音乐库时可用明确标记的简单程序伴奏。输出 master gain，防止混音削波。

音乐情绪应支持真实内容。短家庭纪念片通常不需要持续强鼓点；活动高潮可以加快切换，情绪结尾可延长一个有意义的镜头。成片时长不能成为虚构情节或反复循环的理由。

## 高级方法知识库：尚未自动实现

- **光流补帧**：估计运动来生成中间帧，可改善慢动作；遮挡、交叉运动、飞溅和快速背景容易出现变形。不是简单重复帧，也不是本工具用于运动分析的光流。第一版关闭。
- **运动跟踪**：随目标移动更新位置，需要明确目标、逐帧一致性和遮挡恢复；普通缩放/位置关键帧不算自动跟踪。第一版不声称支持。
- **复杂抠像**：头发、透明物体、运动模糊需细致边缘处理。矩形蒙版只限制显示区域，不代表已经把人物从背景分离。
- **连续曲线变速**：速度随时间连续变化，需控制曲线、源时间映射和声音。多段恒速的拼接不能描述为连续曲线。

## 查阅来源

- [Adobe：J/L cut](https://www.adobe.com/jp/creativecloud/video/discover/j-cut-and-l-cut.html)：声音与画面在不同时间切换。
- [Adobe：Time Remapping](https://helpx.adobe.com/sg/premiere/desktop/edit-projects/change-clip-speed/change-clip-speed-and-duration-using-time-remapping.html)：速度关键帧与平滑速度变化。
- [Adobe：Time Interpolation](https://helpx.adobe.com/ca/premiere/desktop/edit-projects/change-clip-speed/apply-time-interpolation-methods-to-adjust-clip-speed.html)：抽帧、帧混合与光流区别。
- [FFmpeg filters](https://ffmpeg.org/ffmpeg-filters.html)：setpts、atempo、overlay、crop、afade、minterpolate 等执行细节。能在 FFmpeg 找到滤镜不等于本技能已实现对应功能。
